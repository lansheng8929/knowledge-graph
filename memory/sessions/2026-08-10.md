## 关键决策

- 可见性 = 组织管辖（上级看下级，跨租户亦然），不按角色特判。
- 流式用 NDJSON + chunked（`StreamingResponse`），非 WebSocket；原非流式接口保留可回滚。
- 测试数据 id 前缀必须全局唯一（`c2` 与旧 `c` 撞 id 的教训）；旧模拟主数据有 `device-N` 这类 id，聚类验证用 `id =~ 'd\\d+'` 精确过滤。
- 流式 node 必须 yield 完整 `{id, data}`（只 yield data 丢 id → `defaultMapNode` 崩）。
