## ABAC 统一模型（2026-08-06 深夜）——密级只管脱敏、可见性只管可见

### 决策
- **密级 classification**：只驱动 L4 脱敏。`clearance >= 数据密级 → 不脱敏`；未打标/公开(0) 不脱敏。**不再参与可见性**。
- **可见性 visibility**：只决定能否看到。`public` 同租户全员 / `internal` 自己及下级（owner/ownerUid 匹配 uid/username/subUids）/ `private` 仅自己。**去掉 secret 档**（存量 secret 兼容按 internal）。团队不再纳入属主范围。

### 改动
- graph-query `pep.py`：`l3_conditions`/`l3_visible` 删掉 classification<=clearance 子句与 teams；内部=自己及下级（新增 ownerUid 匹配）。`masking.py`：改为 `clearance >= 数据密级` 判定。
- OPA `kg.rego` + `kg_test.rego`：allow 去掉 clearance_ok；可见性三档 + ownerUid；测试 20/20。
- import：`TagConfig` 加 `ownerUid`（服务端注入 subject.uid，不可伪造）；`permissions.py` 可见性集合去掉 secret（VALID_VISIBILITY/ORDER/MIN_CLEARANCE）；validator 仍要求 owner 非空（admin 不自动填充，前端经 options.defaults.owner 带值）。
- graph-ingestion：`IngestNode/IngestLink` 加 `ownerUid`，_node_tags/_link_tags + props 写入；`tags.py` VALID_VISIBILITY 去掉 secret。
- 前端：`VISIBILITY_LABELS` 去掉 机密。
