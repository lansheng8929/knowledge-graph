## 关键决策

- 壳层路由用**轻量自研 router**（History API），不引入路由库；子应用路由仍归 single-spa
- 组件体系用**原生 Web Components + 自研 `BaseComponent`**，不引入 Lit
- 导航 `<a>` 必须自行拦截（single-spa 不拦截普通链接），否则实为 MPA 整页刷新 → 闪烁
- 路由过渡只动 `opacity`/`transform`、统一 `--ease-out`、时长 <300ms
