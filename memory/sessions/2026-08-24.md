## 关键决策

- 全局 CSS 共享到 Shadow DOM 采用 Constructable Stylesheets 单一实例（Lit 3.x 原生支持 `CSSStyleSheet` in `static styles`），避免在每个组件复制规则，可扩展。
- chat 主题色跟随全局 `--primary`（玫红：浅色 #E94560 / 深色 #F43F5E），不单独硬编码；主题切换由 graph-app `ThemeProvider` 设 `<html data-theme>` + `localStorage["kg-theme"]`。
- 侧栏交互分层：桌面 = 折叠 rail + 拖拽调宽；移动端 = 抽屉。默认桌面展开、移动收起（`matchMedia("(max-width: 640px)")` 判断）。
- 用户工作偏好：始终优先最长远/可演进方案（已记入 `/memories/working-preferences.md`）。
- 模块理解新增 `memory/modules/theme-tokens.md`（主题 token 单一来源 / 主色玫红 / data-theme 切换 / 透明度语法坑）。
